# Overview

A simple implementation of cdb in Ada; I was looking for something useful that would flex a bit more
testing, and figured this would at least be useful to myself and others. Currently, only a cdb dumper,
but will aim to make the full suite of cdb tools available to Ada.

# Building

For now, a simple `gnatmake cadab_dump.adb` should suffice, but as I add functionality I'll aim  to support
alire & tada.
